# plant-advisors

Команда ИИ-советников по выращиванию растений на базе нативных субагентов
Claude Code. Один оркестратор принимает вопрос, распределяет его между
4 специалистами и выдаёт итоговый вердикт. Никакого самописного кода,
сетевых запросов и внешних API.

## Архитектура

```
Вы ──► Оркестратор (CLAUDE.md)
            ├──► soil-expert        — субстрат, полив, подкормка, рециклинг
            ├──► plant-pathologist  — болезни и лечение
            ├──► entomologist       — вредители и борьба с ними
            └──► growbox-expert     — PPFD, VPD, генетика, тренировки, харвест
```

- **Оркестратор** — правила в [CLAUDE.md](CLAUDE.md): кого звать, лимит
  2 раунда на вопрос, защита от зацикливания (ответ ≥80% совпадает с первым —
  стоп), формат вердикта.
- **Специалисты** — файлы в [.claude/agents/](.claude/agents/), работают на
  модели `haiku`, инструменты: `Read`, `Write`.
- **Отчёты** — каждый специалист сохраняет полный отчёт в
  `reports/<agent>_report.md`, а в чат возвращает только 1–2 ключевых вывода
  (экономия токенов). Отчёты в git не попадают (кроме `reports/.gitkeep`).

## Как пользоваться

1. Откройте Claude Code в этой папке — `CLAUDE.md` подхватится автоматически.
2. Задайте вопрос, например: «Нижние листья желтеют, в боксе 28 °C, 3-я неделя
   цветения — что это и что делать?»
3. Оркестратор вызовет нужных специалистов и вернёт вердикт: резюме,
   таблицу «агент → вывод → уверенность» и рекомендацию.
4. Полные отчёты — в `reports/`.

## Как добавить нового агента

1. Создайте `.claude/agents/<имя>.md` с frontmatter:

   ```yaml
   ---
   name: <имя>
   description: <кто это и когда звать>
   model: haiku
   tools: Read, Write
   ---
   ```

   и телом промпта: роль, формат ответа (JSON + 1–2 вывода), путь отчёта
   `reports/<agent>_report.md`.
2. Допишите строку в таблицу «Когда кого звать» в [CLAUDE.md](CLAUDE.md).
3. Перезапустите сессию Claude Code, чтобы агент подхватился.
